# Security policy

prybar parses untrusted files (models, packages, textures). A crash, hang,
out-of-bounds read, path escape on unpack or code execution from a crafted
file is a vulnerability.

## Reporting

Report privately through
[GitHub security advisories](https://github.com/ds-kimi/prybar/security/advisories/new).
Do not open a public issue. Include the prybar version, OS, and a minimal
crafted file or the steps to build one (never a copyrighted game file).

You get an answer within 7 days. Fixes ship in the next release and the
advisory is published once users can update.

## Supported versions

Only the latest release gets security fixes.
